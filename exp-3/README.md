# Experiment 3 — Basic SQL Queries

## Aim
Create an Employee–Department–Project relational database, insert 30 employees across five departments and eight projects, and demonstrate common SQL queries.

## How to run
Run `exp-3.sql` in MySQL Workbench or another MySQL client. The database creation and insert statements are intended for a fresh setup and should not be rerun against tables that already exist.

## Expected result
The database contains 30 employee rows, five department rows, and eight project rows. Each query displays the particular details described in its comment.
